# chiffrement_messages
# Outil de chiffrement de messages

Projet personnel en Python (2022). L'outil chiffre et déchiffre un message avec quatre méthodes :

- ROT13 : chaque lettre est décalée de 13 places dans l'alphabet
- César : chaque lettre est décalée d'un nombre de places choisi
- Vigenère : le décalage change à chaque lettre selon un mot-clé
- Polybe : chaque lettre est remplacée par ses coordonnées dans une grille de 5 x 5

## Organisation du code
Chaque méthode a sa propre fonction. On peut ajouter une nouvelle méthode sans modifier les autres.

## Tests
Pour chaque méthode, j'ai vérifié que le déchiffrement d'un message chiffré redonne le texte d'origine.

## Lancer le programme
Python 3 est nécessaire. Lancer le fichier Python du projet.
